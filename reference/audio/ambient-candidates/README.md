# Пробный камин

Оригинальный программный синтез, не запись реального камина и не результат генеративной аудиомодели.

`ambient-fire-loop.wav`: 30 с, PCM16 stereo 48 kHz. Низкочастотный фон горения и 44 негромких события потрескивания. Шум, модуляция и размещение событий рассчитаны циклически.

`ambient-fire-seam-preview.wav`: 12 с, стык на 6-й секунде.

Проверены формат, отсутствие клиппинга и скачок отсчётов на границе. Реалистичность и удобство длительного прослушивания не оценены на слух; требуется пользовательское прослушивание. В игру пока не подключено.

Воспроизведение: отдельный тихий атмосферный слой; окончательную громкость выбрать в контексте музыки. Скрипт воспроизводим с Python + NumPy.
